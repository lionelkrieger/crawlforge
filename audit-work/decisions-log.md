| D-009 | 2026-11-17 | **CrawlForge is the owner's own tool first, with the intent to make it available later to other SEO specialists** (people currently paying for Sitebulb or Screaming Frog premium). | Build for single-user desktop use now, but do not foreclose distribution. Distribution prerequisites to record as future spec items, not current build work: licensing or activation (currently excluded by spec §3 and §4.1), an update channel (spec §2.6 forbids update checking), Windows code signing, an installer, opt-in crash reporting, and possibly macOS support. |
| D-010 | 2026-11-17 | **CrawlForge will be distributed as open source.** | Supersedes the licensing/activation item in D-009: no licence keys, entitlements or accounts are needed, which is consistent with spec §4.1. | D-011 | 2026-11-17 | **Licence: AGPL-3.0, with a contributor licence agreement (CLA) required from the first outside contribution.** | Users and agencies running CrawlForge (including for paid client work) have no obligations; anyone offering a modified version as a network service must publish their changes. Admin: LICENSE file, README notice, optional source headers, CLA document plus a CLA-check bot on the repository before accepting contributions. Dependencies under MIT/Apache are compatible.
