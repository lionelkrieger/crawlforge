# CR-024: Indexable means search-indexable

| Field | Value |
|---|---|
| Type | clarification |
| Status | applied |
| Approved | 2026-11-18, owner (build-plan ambiguity review) |
| Decisions | D-020 |
| Capabilities | CAP-B-036, CAP-B-037, CAP-B-038 |
| Files | 04/01 §7.4 |

## Rationale

The phase-08 harness found the noindex fixture page stored as indexable while the noindex finding fired, because `indexable` had no defined meaning (fetchable vs search-indexable).

## Change

§7.4 defines indexable as search-indexable. The stored flag on the noindex trap is therefore a product defect, routed to phase 09 (rule engine / URL records).
