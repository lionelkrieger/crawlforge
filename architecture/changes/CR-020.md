## Rationale

§7.5 requires a per-rule priority/importance ranking and a remediation-difficulty indicator, but the locked finding contract has no fields for them, so builders would have to choose between a contract change and a JSON convention.

## Change

§7.5 states both are typed fields across storage, REST, hub and MCP, filterable and sortable. Builders implement them as an additive contract change with contract-conformance tests.
