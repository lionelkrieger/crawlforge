## Rationale

§7.4 lists deprecated types as an example check but §7.13 never specified it; Microdata itemprop URL or prefixed terms were left unresolved while RDFa resolves them.

## Change

Deprecated means superseded in the bundled vocabulary or on a bundled, versioned list of retired or restricted rich-result types, never fetched at run time. Microdata terms resolve to the same local names as RDFa and JSON-LD. **Build follow-up:** phase-10 structured-data item.
