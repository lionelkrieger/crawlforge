## Rationale

HTTP-mode capture records no subresource sizes, so the oversized-image check could only measure data-URI images and silently passed the rest.

## Change

Transferred bytes are used where the capture mode records them; in HTTP mode non-inline images are reported as not measured. **Build follow-up:** the rendering phase supplies subresource sizes.
