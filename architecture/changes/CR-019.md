## Rationale

On 2026-11-16 the product owner ratified option (a): the literal p95 ≤ 16.7 ms gate is unachievable in headless Chrome because the frame clock itself jitters 0.1 to 0.3 ms while the grid genuinely sustains 60 FPS. The ruling was recorded only in the v1.1 build manual (`buildplan/v1.1/AGENT-INSTRUCTIONS.md`), leaving the architecture contradictory.

## Change

Criterion #40 and the two performance tables now state the ratified composite gate. `FIDELITY-AUDIT-REPORT.md` is left unchanged as the v1.0 fidelity record.
