## Rationale

D-003: bundle a pinned Chrome for Testing build so rendered results are reproducible between audits and machines (D-009 raises its priority for distribution). Today no browser is bundled and the host never passes a bundled or configured path, so rendering uses whatever Chrome or Edge is installed and drifts with auto-updates.

## Proposed text

**New §5.6.3 Browser provisioning:**

> - The product bundles a **pinned Chrome for Testing build** (full build, run headless) as its default rendering browser. The pinned version changes only with a product release and is recorded in the release notes.
> - Browser resolution order: (1) bundled browser; (2) a user-configured executable path set in Settings; (3) a locally installed Chrome, then Edge. Runtime download of any browser or driver is prohibited (offline-first).
> - Every rendered URL record and every audit records the browser product and version used.
> - If no browser resolves, rendering-dependent modes fail at pre-crawl validation with a clear local error; non-JS capture remains available.

**§8.9 packaging manifest** gains: the pinned browser build and its licence notices.

## Traceability

§5.6.3 carries `> Capabilities: CAP-A-X11 · Decisions: D-003 · Change records: CR-007`.

## Open questions

1. Redistribution terms of Chrome for Testing must be confirmed in the licence audit (O-006) before public release.
2. Installer size impact acceptable? Alternative: a separate optional browser package.
3. Update cadence for the pinned version (every release, or quarterly?).

## Impact

Packaging (CR-014), Settings UI (browser path), pre-crawl validation (§5.1). Audit comparison should flag browser-version changes between compared audits.

## Resolutions (owner, 2026-11-17)

1. Chrome for Testing redistribution: **confirmed in the licence audit** before public release (not a decision).
2. Delivery: **inside the installer**.
3. Update cadence: **with each release, at least quarterly**.

Applied with these resolutions. Where the applied text differs from the proposed text above, the applied text in the architecture is authoritative.
