# CR-022: Configuration-editor tabs for undelivered features render disabled

| Field | Value |
|---|---|
| Type | clarification |
| Status | applied |
| Approved | 2026-11-18, owner (build-plan ambiguity review) |
| Decisions | D-019 |
| Capabilities | CAP-K-X01 |
| Files | 06/04 §1 |

## Rationale

Several UI-04 tabs configure engines delivered in later phases; the surface map did not say whether they are hidden or shown disabled.

## Change

Undelivered tabs and controls render disabled with an "Available in a later build" note; they are never hidden or stubbed, and they do not count as meeting a binding.
