## Rationale

The code map showed MySQL was never live (the host always constructs SQLite; the MySQL provider exists only inside a connection test; the provider-switch orchestrator has no callers), and the phase-08 amendment made its parity tests skip without a server. Finishing it would cost a full second provider of work and testing for little value in a desktop tool.

## Change

SQLite is the only provider in this version; the provider contract stays so MySQL can return later. Criterion #18 is deferred, the settings screen shows local database information instead of provider selection, CAP-L-X03 moves to the deferred list. **Build-plan follow-up (orchestrator):** remove CAP-L-X03 and criterion #18 from the phase-12 workpiece that cites them and from the phase-15 re-baselining list; archive export/import (CAP-L-X02) stays in scope.
